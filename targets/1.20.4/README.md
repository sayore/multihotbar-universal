# MultiHotbar for Minecraft 1.20.4

This source target builds the **Fabric + NeoForge** variants of MultiHotbar 0.2.2 with Java 17 compatibility.

For the illustrated overview, installation steps, and matching release JARs, see the [main README](../../README.md).

Build this target from the repository root:

```sh
./build-matrix.sh 1.20.4 both
```

The [build report](../../BUILD_REPORT.md) records verification across the release matrix.
